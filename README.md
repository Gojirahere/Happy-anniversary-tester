# FOR KAMMO — Playful Edition

A full-screen cinematic + playful anniversary experience for Kammo.

## What's new
- Longer personal letters (before-you + heavy-days)
- **Would you rather** mini game
- **Quick quiz** about the relationship
- **Catch the hearts** interactive mini-game (tap 7 hearts)
- Soft challenge for later
- 3D particle heart that opens on the first page
- 3D lotus that blooms
- 3D butterflies that fly around opened photos
- Fairy-dust sparkles on photo open
- Drag-to-spin photo gallery + lightbox
- 14 scenes total

## Photos
Place your images here:
`assets/photos/01.jpg` … `assets/photos/07.jpg`

Keep the exact filenames.

## Run
Open `index.html` in a browser, or push to GitHub Pages from the `main` branch root.

## Controls
- Buttons
- Swipe left/right
- Mouse wheel
- Arrow keys / Page Up / Page Down
- Drag the photo ring
- Tap hearts in the mini-game
